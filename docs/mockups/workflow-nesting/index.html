工作流嵌套控制流 · 可视化方案预览

针对「电商一键出商品图」工作流（19 步 · 嵌套深度 4）提供三种可视化方案。当前生产版本只展开首层控制流的 body，方案目标是让 `scene-refine-loop` 内的 `refine-subloop` 和 `check-final-result` 的 `then/else` 分支也能被看到。

方案 A · 最轻

抽屉下钻

顶层 DAG 保持现状；容器内嵌套子容器显示为可点"胶囊"，点击从右侧抽屉打开独立 DAG 视图，支持递归钻进任意深度。

  • 复用现有布局组件，改动最小
  • 面包屑导航，深度不限
  • 同屏只看一层，无法并列比较

 方案 B · 中等

Inline 就地展开

容器 body 内的嵌套容器以 chevron 原地展开，支持两层 inline，再深的层级自动 fallback 到抽屉；顶栏提供"全部展开 / 收起"工具按钮。

  • 不跳页，一屏看多层
  • 深层嵌套时卡片高度会变高
  • inline 内难画 DAG 边（只能纵向列）
打开预览 →
 方案 C · 最重

React Flow 子图

使用 @xyflow/react 的 parent/group 机制，每个容器成为真正的分组节点，内部画独立 DAG 并保留依赖边；原生支持缩放、平移、小地图。

  • 一次性呈现所有嵌套层级的完整拓扑
  • 能正确展现 if-else 双分支、while body 内部并行
  • 需要完整替换现有 WorkflowDslGraph 组件
