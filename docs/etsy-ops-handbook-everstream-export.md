| 三、Etsy后台数据字段解读 |  |  |  |
|  |  |  |  |
| ✅ (一)、Stats 总览页 |  |  |  |
|  路径：Shop Manager >Dashboard |  |  |  |
| 字段解释： |  |  |  |
|  |  |  |  |
| 字段 | 含义 | 核心作用 |  |
| Total Views | 所有 Listing 的详情页"被点击进入"的次数总和（自然+广告）；不是曝光量，而是用户点击进入商品页面的总次数（可能同一用户多次点击多个商品） | 粗略看店铺受欢迎度 |  |
| Visits | 店铺及Listing的访客数(点击进店铺,或者点击进Listing的详情页),以访客为单位,是人数 | 一个访客点开任意产品或店铺主页，都只算 1 次注意：Views则是同一访客点了你 3 个商品详情页，就算 3 次 Views |  |
| Orders | 所有来源（自然+广告）的订单总数 | 用于计算店铺整体转化率 |  |
| Revenue | 总营收，加币 | 店铺过去30天总销售表现 |  |
|  |  |  |  |
| ✅ (二)、Stats > Listing Performance（商品详情页） |  |  |  |
|  路径：Shop Manager > Stats > Scroll down to listings |  |  |  |
| 字段解释： |  |  |  |
|  |  |  |  |
| 字段 | 含义 | 核心作用 |  |
| Views | 单个 Listing 被查看的总次数（点击详情页）；包括自然点击和广告点击产生的总页面打开数 | 包括自然点击和广告点击产生的总页面打开数 |  |
| Favorites | 收藏次数 | 潜力热卖指标，用户兴趣信号 |  |
| Orders | 订单数（自然+广告） | 评估 Listing 实际转化力 |  |
| Revenue | 销售额（加币） | 评估高单价高转化产品 |  |
|  |  |  |  |
| ✅ (三)、Etsy Ads 面板 |  |  |  |
|  路径：Shop Manager > Marketing > Etsy Ads |  |  |  |
| 字段解释： |  |  |  |
| 字段 | 含义 | 核心作用 |  |
| Views | 商品广告的曝光次数（即在广告位上被看到的总次数） | 判断广告覆盖范围 |  |
| Clicks | 用户点击广告的次数（进入详情页）;这个点击只计算广告引起的行为，不包含自然流量点击 | 用于计算点击率 CTR |  |
| Click Rate | Clicks ÷ Views | 衡量广告素材吸引力（主图/标题） |  |
| Orders | 广告带来的订单数 | 用于计算转化率 CVR |  |
| Revenue | 广告产生的销售额（美元） | 用于计算 ROAS |  |
| Spend | 过去30天在此商品广告上的支出 | 判断广告成本与效果 |  |
|  |  |  |  |
| ✅ (四)、Etsy Ads > List View（商品广告表现） |  |  |  |
|  路径：Etsy Ads > 切换到 List view 模式 |  |  |  |
| 字段解释： |  |  |  |
| 字段 | 含义 | 核心作用 |  |
| Views | 广告被展示的次数，也叫"曝光量"→ 你的广告在 Etsy 平台上的搜索页、推荐位、浏览页等被看到的总次数（不一定有点击） | 衡量覆盖量 |  |
| Clicks | 用户点击广告的次数（进入详情页）;这个点击只计算广告引起的行为，不包含自然流量点击 | 衡量素材吸引力 |  |
| Click Rate | CTR = Clicks ÷ Views | 封面图/标题优化依据 |  |
| Orders | 广告转化订单 | 广告质量参考 |  |

| 八、店铺CVR统计的意义： |  |  |  |
| 公式：CVR = Orders÷ Visits × 100% |  |  |  |
|  |  |  |  |
| ✅ 判断你整个店铺的「转化效率」 |  |  |  |
| 它能帮你回答这些问题： |  |  |  |
|  |  |  |  |
| 想法 | CVR 能否回答 |  |  |
| 我的店铺吸引了很多人来看，但下单的人多吗? | ✅ |  |  |
| 是不是很多人点进来看，但没买? | ✅ |  |  |
| 我是不是应该优化产品页或价格? | ✅ 通过 CVR 低可以判断 |  |  |
| 广告吸引了访客，但是否有效转化? | ✅ 配合广告数据一起看 |  |  |
|  |  |  |  |
|  举例说明： |  |  |  |
| 假设： |  |  |  |
| • 过去30天 Visits = 10,000 |  |  |  |
| • Orders = 320 |  |  |  |
| CVR = 320 ÷ 10,000 × 100% = 3.2% |  |  |  |
|  |  |  |  |
| 解读： |  |  |  |
| • 每 100 个访问者里，大概有 3 人下单 |  |  |  |
| • 如果你 CVR 能达到 3%~5%，通常是一个比较健康的店铺 |  |  |  |
|  |  |  |  |
| ✅ 建议： |  |  |  |
|  |  |  |  |
| CVR 数值 | 店铺表现 | 优化建议 |  |
| ≥5% | 很优秀 | 可以加大广告预算，打造爆款 |  |
| 3%~5% | 正常 | 可继续观察，逐步优化详情页 |  |
| <3% | 偏低 | 检查详情页、定价、评价、物流时间等 |  |

| 四、Etsy Ads 关键数据指标解读 |  |  |  |
| 指标名称 | 计算公式 | 含义 | 优化目标 |
| Impressions（曝光量） | 广告展示次数 | 广告被用户看到的次数 | 提高曝光量 |
| Clicks（点击量） | 用户点击广告的次数 | 用户对广告感兴趣并点击 | 提高点击量 |
|  |  |  |  |
| CTR（点击率） | Clicks / Impressions | 广告被点击的比例 | >1%为良好 |
| CPC（单次点击成本） | Spend / Clicks | 每次点击的平均成本 | 降低CPC |
| Orders（订单量） | 广告带来的订单数 | 广告转化的订单数量 | 提高订单量 |
| CVR（转化率） | Orders / Clicks | 点击后产生订单的比例 | >2%为良好 |
| Revenue（广告收入） | 广告带来的总收入 | 广告订单的总金额 | 提高收入 |
| Spend（广告花费） | 广告总花费 | 投入的广告费用 | 控制花费 |
| ROAS（广告投产比） | Revenue / Spend | 每1美元广告带来的收入 | >3为盈利 |

| 五、广告优化策略 |  |  |  |
| 优化场景 | 数据表现 | 优化动作 | 预期效果 |

| 2. 点击率低 | CTR < 1% | • 优化主图质量<br>• 调整标题吸引力<br>• 检查价格竞争力 | 提高CTR到1%以上 |
| 3. 转化率低 | CVR < 2% | • 优化产品描述<br>• 增加产品图片<br>• 检查价格和运费 | 提高CVR到2%以上 |
| 4. ROAS低 | ROAS < 3 | • 暂停低效产品广告<br>• 提高客单价<br>• 降低广告成本 | ROAS达到3以上 |
| 5. 花费过高 | Spend增长但订单不增 | • 降低广告预算<br>• 暂停低效产品<br>• 优化关键词 | 控制成本 |

| 尽量避免差评与纠纷 |

| 7. 其他特殊规则 |
| Sanction Policy：不得向受制裁国家发货（如俄罗斯部分地区、受禁运国家）。 |
| Belarus & Russia Rules：特定地区卖家受到更多限制。 |
| P2B Regulation：欧盟法规要求平台对卖家透明，Etsy 必须说明排名规则、账户停用原因，卖家有权上诉。 |
|  |
|  总结：作为卖家必须特别注意的 5 大关键点 |
| 合规与禁止事项：禁止纯代发、禁止侵权、注意产品安全法规。 |
| 税务与报告：确保 Etsy 上报数据与你报税一致。 |
| 知识产权：保护自己的原创，避免侵犯他人版权。 |
| 退货与客户服务：尤其在欧盟市场，遵守 14 天退货规定，保持高服务水平。 |
| 账户安全：保持卖家信息更新，及时处理 Etsy 的验证与提醒，避免店铺停用。 |
